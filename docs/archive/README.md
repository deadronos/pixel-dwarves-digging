# Archive

Historical design notes for work that has shipped. Every GitHub issue these
files describe is closed. Keep them for context, but don't treat them as
current: the code, tests and [`../game-design.md`](../game-design.md) are the
source of truth.

| Folder | Contents |
|---|---|
| `issues/` | Issue write-ups from the 2026-08-20 and 2026-08-30 reviews (#9, #42–#47) |
| `reviews/` | The 2026-08-20 in-depth review and its evidence |
| `superpowers/specs/` | Design specs, one per feature or fix |
| `superpowers/plans/` | Step-by-step implementation plans matching the specs |
| `superpowers/reports/` | Post-implementation reports (refactor scan, renderer optimization) |

Files are named `YYYY-MM-DD-<topic>.md`. A spec and its plan share a date and topic.
