# Issue 12, 13, and 15 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make progression upgrades and hauling policy affect simulation behavior, harden planned-building completion against overlapping reservations, and increment manual run numbers consistently.

**Architecture:** Keep the renderer-independent simulation model. Pass the prospecting level into deterministic world generation, use satchel level to increase haul movement throughput, and make storage selection honor the active hauling policy. Reuse the existing placement revalidation at construction completion and add a stale-plan regression test.

**Tech Stack:** TypeScript, Vitest, Zustand, Vite, Biome.

- [x] **Step 1: Thread prospecting level through deterministic generation**

  Add an optional `prospecting = 0` parameter to `generateWorld`, pass it to `blockForDepth`, and increase the mineral-roll thresholds by a small deterministic bonus per prospecting level. Pass `upgrades.prospecting` from both `createInitialSimulation` and `startPrestige`; existing callers without the third argument remain level 0.

- [x] **Step 2: Use satchel level for haul movement throughput**

  In the engine movement branch, compute movement steps as `1 + moveSpeed`, plus `satchel` when `task.kind === 'haul'`, capped by the remaining path length. This gives satchels a measurable hauling effect without changing save shape or carried-material accounting.

- [x] **Step 3: Make storage selection honor hauling policy**

  In `selectStorageDestination`, sort candidates using the policy: `nearest-stockpile` ranks the completed primary stockpile before distance, while `finish-current-route` ranks the excluded dwarf’s currently assigned building first when it remains reachable and has capacity. Include the policy and active route identity in `digSafetyKey` so cached safety results cannot ignore a policy change.
